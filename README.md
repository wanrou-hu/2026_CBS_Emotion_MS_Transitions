# EEG Microstate Transitions During Naturalistic Emotion Processing

## Overview

This repository accompanies the study *Dual Transition Organization of EEG Microstate Dynamics During Naturalistic Emotion Processing*. Cyborg and Bionic Systems (2026)

The study investigates the organization of EEG microstate (MS) transitions during naturalistic emotion processing, focusing on emotion-shared (ES) and emotion-differentiated (ED) transition patterns. The analyses further examine the relationship between transition dynamics and subjective emotional experience, with external validation and an exploratory clinical extension.

## Repository Contents

The repository provides analysis scripts and supporting data associated with the study, including:

- **MS identification:** Two-stage clustering, template selection, back-fitting, and microstate statistics extraction using the MST1.0 toolbox.
- **Transition organization:** First-order transition probabilities and ES/ED transition analyses.
- **Sequence analysis:** Targeted and full-dictionary 3-gram analyses.
- **Validation and supplementary analyses:** Robustness assessments and additional analyses supporting the reported findings.


## Software and Dependencies

Microstate identification was performed using the MST1.0 microstate analysis toolbox within the EEGLAB environment.
